# Collectibles, roles, and scene art

Generated with the built-in `image_gen` tool, one image per subject. The role prompts used `project-lead.png` as a style reference only. Generated PNGs were converted to WebP for the game while preserving transparency in role portraits. The game draws all names and effects as live canvas text.
