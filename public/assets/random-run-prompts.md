# New generated art for randomized runs

The following prompts produced the final assets copied into this directory. These join the earlier art and prompts in the project.

## Budget Goblin (`budget-goblin.png`)

```text
Use case: stylized-concept
Asset type: isolated crisis character art for a satirical browser game about software project management
Primary request: The Budget Goblin, a sly but charming 1990s office goblin in a little accountant vest, juggling a nearly empty coin purse, a tiny calculator, and a tower of unread procurement forms. Expression playful and calculating; a visual metaphor for a surprise budget freeze.
Style/medium: polished hand-painted editorial cartoon with warm ink outlines and textured gouache, matching a whimsical 1990s software office game.
Composition/framing: single full-body character centered, clear silhouette, readable at 150 px, generous padding.
Color palette: warm cream, dusty teal, muted coral, mustard brass, deep navy ink.
Constraints: transparent background, no environment, no floor, no legible text, no logo, no frame, no watermark.
```
