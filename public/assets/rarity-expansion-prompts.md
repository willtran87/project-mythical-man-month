# Rarity expansion artwork prompts

Six skill scenes were generated with OpenAI's built-in image generation tool and converted to WebP for the game. Each scene can represent related cards in the same skill family.

## Shared prompt

> Square skill-card illustration for a polished satirical fantasy deckbuilder about a chaotic 1990s software project. Painterly editorial cartoon, crisp ink silhouette and textured gouache, navy shadows, cream paper, teal, coral, antique brass. One strong readable focal action, high thumbnail contrast, safe margins for a wide crop. No text, letters, numbers, UI, border, logo, watermark. Subject:

| Final file | Subject suffix | Used by |
